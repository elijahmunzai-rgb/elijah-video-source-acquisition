## Practical acceptance gates to close

1. Film-level storyboards with 3-6 second hook, readable cinematographic camera plan, actor blocking, character and location bibles.
2. Legally licensed and consented real actors OR specific open model weights/inference hardware and rights for synthetic performance.
3. Track camera movement from actual footage with calibration/occlusion/reprojection QA, composite high-quality CG convincingly.
4. Full sequence audio: human-grade dialogue or rights-cleared VO, sync, realistic SFX, actual music/score and dialogue mixing.
5. 1080p minimum real export at 24/25/30 fps, visually plausible complex action and eye/hand/face continuity; full scene-viewer QC for moving shots. 4K/high frame rates when warranted.
6. Real 30s, 2min, 10min encoded outputs with audio stats, no motion discontinuities, human side-by-side blind reference review. Don't assert Hollywood until all required stages pass.
7. For each upstream source: license/security/readme audit, dependency/environment compatibility; install and run **only security-vetted** code in isolated sandboxes. Log each target's pass/fail and reasons. Never execute 318 arbitrary upstream setup scripts blindly to inflate a count.
