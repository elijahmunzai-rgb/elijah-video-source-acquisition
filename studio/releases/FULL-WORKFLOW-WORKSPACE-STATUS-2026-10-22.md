## Implemented code on isolated feature branch
- Full web editor at `GET /studio` and `/studio.html`, linked from control room `/`.
- Duration presets 15,30,60,120,300,600 plus custom planning 5..3600 seconds; aspect landscape/portrait/square.
- Editable shot durations, scene captions, narration, real-source footage selector and source in-point, explicit rights consent.
- Local-browser project drafts and JSON import/export. This is **not a secure multi-device project database**.
- Voice modes: eSpeak free CPU demo, no voice, recorded voice marked **not supported without private media storage**. Music modes: original generated ambient, no music, licensed file marked **not supported without storage**. eSpeak is not professional voice acting.
- Strong validated public-only project contract `studio-spec.mjs`, `POST /api/studio/validate`, GET capabilities, safe 120KB cap; prevents repeated overlapping media, missing rights, unsupported inputs, narration falsely marked enabled, inadequate real shot assets, unauthenticated private/client content.
- Existing `/api/session` login gate, CSRF and rate limits retained. `POST /api/studio/render` uses **single-repo GitHub Contents:Write** to create an approved public request file under `studio/full-workflow/requests/film-<timestamp>-<random>.json` on the fixed beta branch (no arbitrary repository, branch or workflow).
- Branch-scoped `.github/workflows/film-studio-full-production.yml` listens for request-file `push` events, validates rights and exact footage in-points, downloads exact approved Mixkit source clips, encodes real H264 full-HD scene clips and joins, generates original synthesized score plus actual eSpeak narration, FFprobes final output, uploads MP4+source metadata+QA to GitHub.
- Existing read-only `/api/jobs` retained for legacy workflow. `GET /api/studio/jobs` lists full film workflow runs on beta and UI displays links to GitHub jobs. **Protected inline browser playback and large movie downloads are not yet implemented**, currently use GitHub artifact links.
- Hostinger Node20 seven-file upload ZIP includes `package.json,server.mjs,operator.mjs,media.mjs,studio-spec.mjs,studio.html,index.html` at root. Built by `.github/workflows/film-studio-full-app-package.yml`, Node20 `npm test` security/route tests pass.
