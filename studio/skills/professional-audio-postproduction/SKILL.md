# Professional Audio Postproduction

Select rights-safe music with real musical structure before picture lock. Prefer recording or licensed track; never default to generated sine-and-noise pulses for client-facing cinematic videos. Foley UI clicks matched to visible events, impacts at motivated cuts, natural ambient bed, and restrained risers. Keep stems separately.

Use `engine/audio_mix.py` to sidechain duck music, compressor on dialogue, add effects, fade, and loudnorm. Run `engine/production_audit.py`; inspect true peak and intelligibility by listening. If narration is requested but not recorded/generated with a properly supported and authorized local voice, do not pass final QA. Low LRA alone is a review flag, not hard proof of poor sound.
