# Video Copywriting and Script Architecture
Write from problem -> credible contrast -> named outcome -> action. Select one primary CTA. Separate `spoken_voiceover` from `exact_visible_text` and `notes`; do not automatically put full voiceover on screen.
- Ads: hook, objection, proof, mechanism, CTA; distinguish real proof from hypothetical treatment.
- Explainers: one concept per beat, definitions before claims, concrete demonstration before conclusion.
- Preserve user-provided exact quotes and claims. Flag unverifiable numbers instead of creating fake performance metrics.
- Preflight: spellcheck, spoken duration at ~125-165 WPM depending on context, legible text duration, native brand capitalization, mobile-friendly line breaks.
Produce a locked copy sheet with `scene_id`, exact uppercase/lowercase visible strings, voiceover, CTA, and approval questions only for blockers.
