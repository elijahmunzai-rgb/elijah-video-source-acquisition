# Creative Quality Gate

Review actual played video, not only stills or `ffprobe`. Score 0-5 in six categories: persuasive story, cinematic shot language, source pixel quality, compositing/typography, music/voice/SFX, originality and faithful brand. Anything <4 is NOT APPROVED. Signs of failure: 5+ repeated typographic cards; unmoving mascot with artificial bob; all shots same framing; no actual actor/object when filmed production requested; monotonous synth beeps instead of music; missing promised voice; subpar details; fake data or incorrect approved logo. If previous user dislikes version, treat as creative failed regardless of past quality label. Fix story and asset quality before adding effects.
