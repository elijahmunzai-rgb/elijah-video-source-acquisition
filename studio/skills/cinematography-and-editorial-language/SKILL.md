# Cinematography And Editorial Language

Define a subject and visible action for every shot, never only a typography card. Shot bible fields: source clip, subject/action, narrative reason, framing wide/medium/detail, light direction and ratio, focus/depth, camera velocity, cut trigger, audio beat, caption region, license. Use motivated transitions, continuity axis and change in scale; storyboard mechanism: problem -> action -> consequence -> offer.

For a 30s SDR/BDR/VA IO Agency film: cold/open 0-3 sec, authentic human/work scene 3-7, prospect->reply->booking as SDR 7-13, discovery->qualification as BDR 13-19, CRM/inbox workflow as VA 19-24, connected team, exact brand mark and CTA 24-30. Only illustrative data labeled as such, no fabricated clients. Use soft practical lighting, black/cyan/blue/white, genuine camera/screen-capture footage instead of over-glowing rectangles.
