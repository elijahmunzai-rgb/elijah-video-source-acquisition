# Creative Direction & Storyboarding
Define emotional promise, audience, single action, distinctive design language, and proof. Produce a beat sheet with columns `start/end | purpose | image | movement | on-screen copy | audio | cut` and decide canvas composition before rendering.
- Hook within first 0.5-2 seconds; visual transformation rather than generic stock-style gradient plus centered headline.
- Give each beat a distinct function: interruption, tension, explanation, resolution, CTA. Avoid seven simultaneous messages.
- Use motivated camera-like motion, restrained textures, deliberate scale, foreground/background separation, modular compositions, optical balance.
- For premium ads develop one hero metaphor through scenes and purposeful reveals. All text gets enough hold time for reading.
- Include no fabricated logos, metrics, reviews, clients, or platform endorsement. If brand files are missing, create an original text treatment marked as a placeholder.
Deliver a concrete scene table and a clearly specified `master visual metaphor` suitable for code implementation.
